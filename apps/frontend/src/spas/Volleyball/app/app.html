Import / Export events

One event per line, comma-separated: Event Name, Event Type, Coach / Trainer / Teacher, Start Date & Time, End Date & Time, Repeat this event, Location. Event Name, Event Type, and Start/End Date & Time are required — dates should look like 07/05/2026 5:00 PM. Leave any other field blank if it doesn't apply. Known event types (event, group, private, tryout, school) get their usual colors; anything else gets an automatically assigned color. Importing adds these events to the schedule — it does not remove or replace existing ones.
Example: Practice, group, Coach Sam, 07/05/2026 5:00 PM, 07/05/2026 6:00 PM, Weekly, Gym A
